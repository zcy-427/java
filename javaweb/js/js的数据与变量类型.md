## 变量声明：`var` vs `let` vs `const`

#### ❌ `var` (老旧，切勿使用)

这是 JS 早期的设计缺陷。

- **作用域混乱**：它没有“块级作用域”（Block Scope）。你在 `if` 或 `for` 循环里定义的变量，居然会跑出来泄露到外面！这在 Java 里是不可想象的。
    
- **变量提升 (Hoisting)**：你可以在定义之前就使用它（虽然值是 undefined），非常反直觉。、

#### ✅ `let` (标准，对应 Java 局部变量)

ES6 (2015年) 推出的新标准。

- **块级作用域**：和 Java 的变量一样，出了大括号 `{}` 就死掉了。
    
- **推荐**：凡是**以后可能会变**的值，都用 `let`。
    

#### ✅ `const` (常量，对应 Java `final`)

- **含义**：一旦赋值，不可修改。
    
- **推荐**：凡是**定义后不打算改**的值，优先用 `const`（比如 API 的 URL、配置项）。

## 数据类型
#### A. 基本数据类型 (Primitive Types) - 存放在栈内存

1. **`number` (数字)**
    
    - JS 不分 `int` 和 `double`！所有数字（整数、浮点数）统统都是 `number` 类型（底层是 64 位浮点数）。
    - **特例**：`NaN` (Not a Number)。如果你拿 "abc" 减去 1，结果就是 `NaN`。
    
2. **`string` (字符串)**
    
    - **Java**：只能用双引号 `""`。
        
    - **JS**：单引号 `'` 和双引号 `"` 都可以！
        
    - **模板字符串**（重点）：反引号 ``。类似于 Java 15+ 的文本块，可以直接换行，还能用 `${变量}` 插值。
```js
let name = '张三';
let msg = `你好，${name}。欢迎来到 JS 世界！`;
```
3. **`boolean` (布尔)**
    
    只有 `true` 和 `false`。
    
4. **`undefined` (未定义)** —— **Java 没有这个！**
    
    - 当你声明了一个变量 `let a;` 但没给它赋值时，它的值就是 `undefined`。
        
    - **含义**：**“这里应该有个值，但还没给。”**
5. **`null` (空)**
    
    - 和 Java 的 `null` 一样。
        
    - **含义**：**“这里专门设置为空，表示没有对象。”**

#### B. 引用数据类型 (Reference Types) - 存放在堆内存

1. **`object` (对象)**
    
    - 不需要像 Java 那样先写一个 `Class` 类，你可以直接创建一个对象（JSON 格式）
```js
// 这就是一个对象，不需要 new User()
let user = {
    name: "Java导师",
    age: 30,
    skill: ["Java", "JS"]
};
console.log(user.name);
```
2. **`function` (函数)**
    
    - 在 JS 中，函数也是一种数据类型！你可以把函数赋值给一个变量，或者作为参数传给另一个函数（这是 Java Lambda 的前身）。
