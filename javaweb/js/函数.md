## 1.传统宣言式 (Declaration)

```js
// 定义函数
function sayHello(name) {
    return "你好, " + name;
}

// 调用函数
let result = sayHello("Java导师");
```

## 2.函数表达式 (Expression) —— 把函数当变量

```js
const add = function(a, b) {
    return a + b;
};
console.log(add(1, 2)); // 输出 3
```

## 3.箭头函数 (Arrow Function) —— 对标 Java Lambda

```js
// 传统写法
const square1 = function(n) { return n * n; };

// 箭头函数简写
const square2 = (n) => n * n;

console.log(square2(5)); // 输出 25
```
